# Retro Arcade — brand guide

**Proposed display name:** Retro Arcade
**Tagline:** *Six cabinets, one index.*

## Why this name

This is the hub that catalogs the six recreations, so it gets the marquee — the sign over the arcade's door.

## The mark

A glowing marquee, a scanlined screen, and a coin slot: the parts of a cabinet every game in the index shares.
